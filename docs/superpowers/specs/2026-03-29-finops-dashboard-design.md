# Agenticbricks FinOps Dashboard — Design Spec
**Date:** 2026-03-29
**Version:** v1.0 (Phase 1 — GCP connector)

---

## Overview

A centralized cost visibility dashboard that aggregates daily spend from multiple platforms (GCP, Claude API, Vercel, GoDaddy, Google Workspace) and displays it as a static React app hosted on GitHub Pages. All infrastructure is free at the expected data volume (<50 MB/month).

**Out of scope for v1:** ML forecasting, automated cost optimization, multi-currency, per-platform drill-down tabs, live data queries.

---

## Architecture

### System Flow

```
GitHub Actions (cron: daily 6am UTC)
  → ingestion/connectors/gcp.ts        # queries GCP billing export in BigQuery
  → ingestion/normalize.ts             # maps to unified cost schema
  → ingestion/bigquery.ts              # upserts into normalized_costs table
  → ingestion/export.ts                # queries last 90 days → writes dashboard/data/costs.json
  → git commit + push costs.json
  → triggers deploy.yml
      → vite build
      → deploy dist/ to GitHub Pages
```

### Stack

| Layer | Technology |
|---|---|
| Ingestion runtime | GitHub Actions (cron) |
| Language | TypeScript / Node.js |
| Storage | BigQuery (GCP project: `agenticbricks-finops`) |
| Dashboard | React + Vite + Recharts + Tailwind CSS |
| Hosting | GitHub Pages |
| Cost | $0/month |

## Data Model

### Unified CostRecord (TypeScript interface)

```typescript
interface CostRecord {
  date: string;        // "YYYY-MM-DD"
  platform: string;   // "GCP" | "Claude" | "Vercel" | "GoDaddy" | "Workspace"
  project: string;    // e.g. "finops", "prod-api"
  resource: string;   // service/SKU name
  cost_usd: number;   // always USD
  metadata: Record<string, unknown>; // platform-specific extras
}
```

### BigQuery Tables

**`normalized_costs`** (real table, partitioned by `date`)

| Column | Type | Notes |
|---|---|---|
| date | DATE | YYYY-MM-DD |
| platform | STRING | GCP \| Claude \| Vercel \| GoDaddy \| Workspace |
| project | STRING | project identifier |
| resource | STRING | service or SKU name |
| cost_usd | FLOAT64 | always USD |
| metadata | JSON | platform-specific extras |

**`daily_aggregates`** (BigQuery view — no extra storage, used for summary queries)

```sql
SELECT
  date,
  platform,
  project,
  SUM(cost_usd) AS total_cost_usd
FROM normalized_costs
GROUP BY date, platform, project
```

> **Note:** `export.ts` queries `normalized_costs` directly (not this view) with a 90-day date filter, so that `costs.json` retains resource-level detail. The `daily_aggregates` view is available for ad-hoc summary queries.

### costs.json structure

```json
{
  "generated_at": "2026-03-29T06:05:00Z",
  "window_days": 90,
  "records": [
    { "date": "2026-03-28", "platform": "GCP", "project": "prod", "resource": "Cloud Run", "cost_usd": 12.40 }
  ]
}
```

## GCP Connector (Phase 1)

Queries the GCP billing export BigQuery table for yesterday's data, normalizes it, and upserts into `normalized_costs`.

```sql
SELECT
  DATE(usage_start_time) AS date,
  project.id             AS project,
  service.description    AS resource,
  SUM(cost)              AS cost_usd
FROM `agenticbricks-finops.billing_export.gcp_billing_export_v1_*`
WHERE DATE(usage_start_time) = DATE_SUB(CURRENT_DATE(), INTERVAL 1 DAY)
GROUP BY 1, 2, 3
```

**Deduplication:** Before inserting, delete all rows in `normalized_costs` where `date = yesterday AND platform = 'GCP'`. Re-running the job is always safe.

## GitHub Actions Workflows

### `ingest.yml`

- **Trigger:** `schedule: cron: '0 6 * * *'` + `workflow_dispatch`
- **Secret:** `GCP_SERVICE_ACCOUNT_KEY` (service account with BigQuery read on billing export + BigQuery write on finops dataset)
- **Steps:** checkout → setup Node.js → install deps → run connectors → run export → commit `costs.json` → push
- **On failure:** job fails visibly in GitHub (email notification). `costs.json` is not updated. Dashboard continues serving last good data.

### `deploy.yml`

- **Trigger:** `workflow_run: workflows: [ingest.yml], types: [completed]` with condition `if: github.event.workflow_run.conclusion == 'success'` + `workflow_dispatch`
- **Secret:** none (uses built-in `GITHUB_TOKEN`)
- **Steps:** checkout → setup Node.js → install deps → `vite build` → deploy `dist/` to GitHub Pages
- **On failure:** ingest data is safe in BigQuery. Re-run deploy manually.

## Dashboard UI

Single-page layout (no router). Read `data/costs.json` at app startup.

### Components

| Component | Description |
|---|---|
| `KpiCard` | Shows total spend for current month + per-platform totals |
| `SpendChart` | Recharts `BarChart` — daily spend over last 30 days, stacked by platform |
| `PlatformBreakdown` | Percentage share per platform for selected period |
| `CostTable` | Sortable table of top resources by cost, filterable by platform |

### Date filter

A simple dropdown (Last 7 days / Last 30 days / Last 90 days) that filters the in-memory `costs.json` data client-side. No API call needed.

## GCP Setup Checklist (one-time)

1. Create GCP project: `agenticbricks-finops`
2. Enable Billing Export → BigQuery (exports to `billing_export` dataset)
3. Create dataset: `finops` (for `normalized_costs` table)
4. Create service account with roles:
   - `BigQuery Data Viewer` on `billing_export` dataset
   - `BigQuery Data Editor` on `finops` dataset
   - `BigQuery Job User` on project
5. Export service account key → add as `GCP_SERVICE_ACCOUNT_KEY` GitHub secret
6. Enable GitHub Pages using the `gh-pages` branch (deploy action pushes built `dist/` there)

## Phase 2 (after GCP connector is live)

Add remaining connectors one at a time. Each follows the same pattern: implement `connectors/<platform>.ts` returning `CostRecord[]`, no other files change.

| Platform | Integration method | Notes |
|---|---|---|
| Claude API | Anthropic billing API or usage logs | Requires project tagging |
| Vercel | Vercel REST API | `/v2/billing/usage` |
| GoDaddy | GoDaddy API or manual CSV | Monthly granularity → spread to daily |
| Google Workspace | Admin SDK / billing export | Per-user license cost |

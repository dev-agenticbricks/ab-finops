## What This Project Is

Agenticbricks FinOps Dashboard — a zero-cost finance dashboard that aggregates daily cloud spend from GCP, Claude API, Vercel, GoDaddy, and Google Workspace, and displays it as a static React app on GitHub Pages.

Full design spec: `docs/superpowers/specs/2026-03-29-finops-dashboard-design.md`

## Commands

### Root
```bash
npm install          # install all workspaces
npm run ingest       # run ingestion pipeline locally (requires GCP credentials)
npm run export       # generate dashboard/data/costs.json from BigQuery
```

### Ingestion (`cd ingestion`)
```bash
npm install
npm run build        # tsc compile
npm run ingest       # run all connectors + normalize + write to BigQuery
npm run export       # query BigQuery → write ../dashboard/data/costs.json
npm test             # run tests
```

### Dashboard (`cd dashboard`)
```bash
npm install
npm run dev          # local dev server (reads data/costs.json)
npm run build        # vite build → dist/
npm run preview      # preview production build locally
```

## Architecture

```
GitHub Actions (cron daily 6am UTC)
  → ingestion/connectors/gcp.ts     # queries GCP billing export BigQuery table
  → ingestion/normalize.ts          # maps to unified CostRecord schema
  → ingestion/bigquery.ts           # upsert into BigQuery normalized_costs table
  → ingestion/export.ts             # queries last 90 days → writes dashboard/data/costs.json
  → git commit costs.json → push
  → deploy.yml triggers → vite build → GitHub Pages
```

Two GitHub Actions workflows:
- `ingest.yml` — daily cron, needs `GCP_SERVICE_ACCOUNT_KEY` secret
- `deploy.yml` — triggers only on ingest success, needs only `GITHUB_TOKEN`

## Key Conventions

**Unified data schema** — every connector returns `CostRecord[]`. Adding a new platform means implementing one file (`ingestion/connectors/<platform>.ts`) only — nothing else changes.

**Deduplication** — before inserting, delete yesterday's rows for the platform from `normalized_costs`, then re-insert. Re-running ingest is always safe.

**costs.json** — lives at `dashboard/data/costs.json`, git-tracked, generated by `export.ts`. Contains last 90 days of resource-level rows. Dashboard reads this file at startup — no API calls at runtime.

**BigQuery tables:**
- `normalized_costs` — real table, partitioned by `date`, written by ingestion
- `daily_aggregates` — view over `normalized_costs`, for ad-hoc queries only

**Dashboard** — single-page React + Vite + Recharts + Tailwind, no router. Date filter (7d / 30d / 90d) filters in-memory data client-side.

## GCP Setup (one-time, do before running locally)

1. Create project `agenticbricks-finops` in GCP
2. Enable Billing Export → BigQuery (dataset: `billing_export`)
3. Create dataset `finops` (tables created by ingestion on first run)
4. Create service account with: BigQuery Data Viewer on `billing_export`, BigQuery Data Editor + Job User on `finops`
5. Export key JSON → set as `GCP_SERVICE_ACCOUNT_KEY` in GitHub secrets and locally as `GOOGLE_APPLICATION_CREDENTIALS`
